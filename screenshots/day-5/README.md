# 📸 Day 5 – Administrative Access

This folder contains screenshots and demo videos from my **Day 5** Linux practice on **Administrative Access**.

## 📂 Contents

- 🖼️ `exit-command.png` – Switching back from the root user using `exit`.
- 🎥 `su-command.mp4` – Demonstrates switching to the **root user** with `su -`.
- 🎥 `sudo commands.mp4` – Demonstrates running commands with **`sudo`**.

## 💻 Commands Covered

```bash
su -
sudo ls /root
sudo whoami
exit
```

⭐ These screenshots and videos demonstrate my hands-on practice with Linux administrative commands and user privilege management.
