# 📸 Day 6 – File Permissions

This folder contains screenshots from my **Day 6** Linux practice on **File Permissions** using the `ls -l` and `chmod` commands.

## 📂 Contents

- 🖼️ **Permission.png** – Viewing file permissions with `ls -l`.
- 🖼️ **File-Permission.png** – Adding execute permission using `chmod u+x` and successfully running `hello.sh`.

## 💻 Commands Covered

```bash
cd ~/Documents
ls -l hello.sh
./hello.sh
chmod u+x hello.sh
ls -l hello.sh
./hello.sh
```

⭐ These screenshots demonstrate how to view, modify, and apply file permissions to execute a Linux script.
