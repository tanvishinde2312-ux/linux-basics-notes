# 📸 Day 4 – Listing Files (`ls`)

This folder contains screenshots from my **Day 4** Linux practice, demonstrating different ways to list and sort files using the **`ls`** command.

## 🖼️ Screenshots

- 📂 **Listing Files** – `ls -1 /var/log`
- 🔄 **Reverse Alphabetical Order** – `ls -r /var/log`
- 📏 **Sort by File Size** – `ls -1S /var/log`
- 🔁 **Reverse Size Order** – `ls -1Sr /var/log`
- ⏰ **Sort by Modification Time** – `ls -1t /var/log`

⭐ These screenshots document my hands-on practice with Linux file listing and sorting commands as part of the **NDG Linux Unhatched** course.
