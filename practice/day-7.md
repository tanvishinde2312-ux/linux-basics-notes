## 💻 Commands Practiced

```bash
cd ~/Documents
ls -l
sudo chown root hello.sh
ls -l hello.sh
cat animals.txt
cat alpha.txt
head alpha.txt
tail alpha.txt
head -n 5 alpha.txt
tail -n 5 alpha.txt
```

---

## 📚 What I Learned

- 👑 Changed file ownership using `chown`.
- 🔐 Verified ownership changes with `ls -l`.
- 🐱 Viewed complete file contents using `cat`.
- ⬆️ Displayed the first few lines using `head`.
- ⬇️ Displayed the last few lines using `tail`.
- 🎯 Used the `-n` option to show a specific number of lines.
