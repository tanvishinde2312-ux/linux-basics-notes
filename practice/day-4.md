**📂 Listing Files in Linux**

Today, I practiced using the **`ls`** command and its different options to view, organize, and understand files and directories in the Linux file system.

## 🎯 Objectives

- 📂 Learn how to list files and directories.
- 📋 Understand the detailed output of the `ls -l` command.

---

## 💻 Commands Practiced

### 📂 List Files

```bash
ls
```

Displays all files and directories in the current directory.

---

### 📋 Long Listing Format

```bash
ls -l
```

Displays detailed information including:

- 📂 File Type
- 🔐 Permissions
- 🔗 Hard Links
- 👤 Owner
- 👥 Group
- 📏 File Size
- 📅 Last Modified Date
- 📄 File Name

---

### 🔄 Reverse Order

```bash
ls -r
```

Lists files in reverse alphabetical order.

---

### ⏰ Sort by Modification Time

```bash
ls -lt
```

Displays recently modified files first.

---

### 📏 Sort by File Size

```bash
ls -lS
```

Displays the largest files first.

---

### 🔁 Reverse File Size Order

```bash
ls -lSr
```

Displays the smallest files first.

---

| ⌨️ `c` | Character Device |
| 🔌 `s` | Socket |
| 🚰 `p` | Pipe |
