# 📅 Day 6 Practice

## 🎯 Topic

**🔐 File Permissions in Linux**

Today, I learned how to view and modify file permissions using the **`ls -l`** and **`chmod`** commands.

---

## 💻 Commands Practiced

```bash
ls -l
chmod u+x hello.sh
chmod u-x hello.sh
chmod u=rwx hello.sh
./hello.sh
```

---

## 📝 What I Learned

- 🔍 Viewed file permissions using `ls -l`.
- 👤 Understood **Owner**, **Group**, and **Others** permissions.
- 🔑 Learned **Read (r)**, **Write (w)**, and **Execute (x)** permissions.
- ⚙️ Changed file permissions using `chmod`.
- ▶️ Executed a script after granting execute permission.
