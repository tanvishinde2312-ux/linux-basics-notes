# 📅 Day 5 Practice

## 🎯 Topic

**🔐 Administrative Access in Linux**

Today, I learned how to use **`su`** and **`sudo`** to perform administrative tasks and understood the difference between them.

---

## 💻 Commands Practiced

```bash
su -
sudo ls /root
sudo whoami
sudo -u sysadmin whoami
exit
```

---

## 📝 What I Learned

- 👤 Switched to the **root user** using `su -`.
- ⚡ Executed commands with administrator privileges using `sudo`.
- 🚪 Returned to the previous user using `exit`.
- 🔒 Learned the difference between `su` and `sudo`.
- ✅ Understood why `sudo` is the safer option for administrative tasks.
